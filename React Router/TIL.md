# 📘 Today I Learned

### 1. 오늘 배운 내용
1. React Router 도입 — BrowserRouter, Routes, Route를 사용해서 /(목록)와 /lions/:id(상세) 두 페이지로 분리함
2. 페이지 간 이동 & 데이터 공유 — useNavigate로 카드 클릭 시 상세 페이지로 이동하고, lions 상태를 App.jsx로 올려서(State Lifting) 두 페이지가 같은 데이터를 공유하게 구현
3. URL 쿼리 파라미터 연동 — useSearchParams를 사용해서 필터/정렬/검색 조건이 URL에 반영되고, URL로 직접 접속해도 해당 조건이 유지되도록 함
### 2. 핵심 정리 (내 언어로)
  아기사자 요약 카드를 눌러 상세 설명 카드로 넘어가기 위해 아기사자들 각각의 아이디를 링크와 연결하여 파타미터 값을 받을 수 있도록 구현해야함을 배웠다. 또 아기사자 페이지를 더욱 깔끔하게 보기 위해 요약 카드를 눌러 상세 설명 카드로 가기 위해서는 서로의 id값이 같아야 파라미터 값을 주고 받을 수 있음을 배웠다.
