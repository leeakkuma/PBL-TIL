## 개선할 점
삭제 버튼 :
삭제가 마지막 카드 삭제로 고정되어 있는데,
원하는 카드를 삭제할 수 있어야 될 것 같음.
예를 들어 카드를 길게 누르면 선택하는 상태로 변하고
선택한 상태에서 선택한 요소들을 제거하는 버튼을
화면 어딘가에 고정해놓던가 하는 식으로 띄워도 좋을 듯합니다
띄우는 방식은 취향 껏 ㄱㄱ

프로필 카드 :
현재는 프로필 카드를 누르면 다른 페이지로 띄우는 방식으로 보이는데, 카드 목록 페이지에서 띄워졌으면 어땠을까? 싶은 생각이 듭니다
그리고 텍스트 중에 화면 양옆으로 가장 긴 텍스트를 기준으로 카드 전체 크기가 산정되는 듯 한데 카드 크기는 어느 정도 정해져있으면 좋을 듯합니다

글자 :
글자가 너무 많은 듯한 느낌이 듭니다
버튼에 있는 글자도 어느정도 생략할 수 있는 부분이 있을 것 같습니다

예를 들어 "아기 사자 추가", "마지막 아기 사자 삭제"도
초록색의 십자와 빨간색의 엑스자로 아이콘으로 간단하게 넣을 수도 있을 것 같습니다

카드 위에 있는 (FRONTEND)와 (BACKEND)도 간략하게 아이콘으로 넣으면 어떤가 싶어요
간단하게 생각해보면 프론트엔드를 모니터나 노트북 등, 백엔드를 서버 등으로 아이콘 표시를 할 수 있을 듯합니다

카드 내용에 있는 CONTACT에 EMAIL, GITHUB, PHONE 등은 고정되어 있는 듯 한데
이 내용도 아이콘으로 바꿔도 괜찮을 듯
스킬에 대한 요소도 글자로 단순하게 있기보단
하나의 아이콘이나 아이콘 + 글자(아이콘에 많은 색상 적용)처럼 적용해도 좋을 듯 합니다
근데 다시 생각해보니 스킬에 대한 요소를 추가하는 방식을 보니까 글자를 넣는 방식이라 적용하기 힘들 것 같기도합니다
Iconify API를 이용해서 아이콘을 검색해서 넣는 방식이 있는 것 같은데 적용하고 싶으시면 AI에게 질문하는게 좋아보입니다

카드에 FRONTEND DEVELOPER나 BACKEND DEVELOPER로 파트에 대해 핑크색상의 글자가 있는데
카드 위에 FRONTEND와 BACKEND가 표시되어 있기도 합니다.
둘 중에 하나는 날리는게 괜찮을 것 같습니다.

색감 :
너무 연한 감이 없지 않아 있는 듯 합니다
항목들이 눈에 어느정도는 구분될 수 있도록 아주 살짝 정도는 좀더 진해도 되지않나?
라는 생각이 드는데, 수정해보신다면 수정해보면서 적절한 색상 찾는 것도 좋아보입니다
근데 이건 취향차이?인 것 같기도 하고 제 심미안도 좋은 편은 아니라 확신이 들진 않습니다
